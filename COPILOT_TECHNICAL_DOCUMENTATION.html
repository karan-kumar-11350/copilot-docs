1. System Overview
AI-powered clinical assistant embedded within Charm EHR

Charm Copilot is an AI-powered clinical assistant embedded within the Charm EHR platform. It provides real-time ambient audio recording, automatic chart note generation, conversational AI, lab opinion, patient summarization, FAQ assistance, and referral generation — all gated behind a subscription tier system.

3.2 Tier Definitions

NONE

  • No Copilot access whatsoever — UI is hidden/disabled
  • All CopilotTierValidator checks throw error 90147

BASIC — Basic (Free)

  • Limited feature set with daily encounter usage limits
  • Accessible modules: FAQ_BOT_ASSISTANT, COMMON_ASSISTANT, ENCOUNTER
  • Encounter limit: configurable per member via copilot_encounter_limit MemberProp (default: 2/day)
  • When limit exceeded, ENCOUNTER module falls back to COMMON_ASSISTANT

ADVANCED — Advanced (Professional)

  • Full feature set with no usage limits
  • All modules: FAQ_BOT_ASSISTANT, COMMON_ASSISTANT, ENCOUNTER, PATIENT_DASHBOARD, LAB_OPINION, NURSE_ENCOUNTER

Race Condition Handling

When both tasks run concurrently, either can finish first. The frontend coordinates via two flags and a temporary store:

ScenarioHandling
Subjective arrives firstDisplay partial note; set flag; wait for assessment
Assessment arrives firstStore in scriber.assessmentResponse; wait for subjective
Both arrive (subjective last)Merge via Object.assign() then single displayInCopilot()
Either errorsClear both flags; show error + Retry button

Sync vs Async Path

When IS_WEBHOOK_ENABLED_FOR_COPILOT = false, the system uses initiateRunWithThread() with an inline polling loop and returns the final response directly in the HTTP response (no WMS).

RAG Pre-Router: copilot/ask NEW

Before every assistant run in Copilot Chat, the frontend calls POST /api/ehr/v1/copilot/ask for intent detection, module routing, and named entity extraction using a lightweight LLM (COPILOT_ROUTER_AGENT). The result enriches the user query with relevant tool schemas and patient/member context before the actual OpenAI run begins. This is the core of the RAG pipeline in Copilot Chat.
